# Documentation index

Start with these files:

- `unified_generator_operator_guide.md`: current generation, review, and
  finalization commands.
- `../src/dynamic_robot_dataset/scenarios/README.md`: the 20 canonical
  subfamily modules and their implementation status.

- `handoffs/`: dated project handoffs retained for provenance.
- `archive/`: superseded plans that explain historical decisions but are not
  runtime instructions.

The corpus and backend YAML registries remain authoritative when prose and
runtime state disagree.
