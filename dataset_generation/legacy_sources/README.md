# Quarantined source snapshots

This directory preserves small snapshots of earlier collaborator generators
for audit and migration provenance. Nothing here is a production import path.

- `mzl7/`: Michael's projectile, rolling, and cloth lineages.
- `zl664/`: earlier local Franka/Robotiq and deformable lineages.
- `zss8/`: harmonizer-era Franka/Robotiq, bounce, and rope lineages.

The snapshots may contain state rewriting, latches, equality grasps, intended
labels that disagree with measured outcomes, or stale absolute paths. Use the
canonical scenario modules instead.
