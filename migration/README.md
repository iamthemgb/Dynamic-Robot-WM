# Migration evidence

This directory is immutable historical inventory and decision evidence. It is
useful for tracing source lineage, duplicates, embodiment corrections, and
known data-quality problems, but it is not an executable generator.

For current operation, use `../docs/unified_generator_operator_guide.md` and
`python -m dynamic_robot_dataset.scenarios list`.

The generated examples and smoke datasets formerly checked in under
`outputs/` are preserved at
`/gpfs/radev/project/sous/zl664/dataset_generation_runs/legacy_inrepo_outputs_20260721/`.
